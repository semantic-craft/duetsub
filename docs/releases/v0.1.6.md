# DuetSub v0.1.6

This patch gives the English subtitle visual priority while keeping Traditional Chinese comfortably readable.

## Highlights

- Enlarges the English line from 82% to 100% of the responsive subtitle base size.
- Sets the Traditional Chinese line to 90% for a quieter secondary hierarchy.
- Makes the overlay model the single source of truth for the rendered line sizes.
- Documents the BBC, Netflix, W3C, and EBU guidance behind the typography decision.
- Refreshes the Chrome Web Store player image to match the new hierarchy.

## Validation

- Full Vitest behavior suite and TypeScript checking.
- Reproducible Chrome MV3 release and Chrome Web Store archive verification.
- Player-relative typography preview at the exact 100% / 90% proportions.
