# DuetSub v0.1.6

[English](#english) | [简体中文](#简体中文)

## English

DuetSub 0.1.6 makes bilingual watching more flexible while keeping official subtitles first.

### Highlights

- Choose any two verified official subtitle languages available for the current title.
- Use the dedicated Language menu to select the top and bottom languages, swap them, or reload official subtitle tracks.
- Keep subtitle ownership and timing reliable through seeking and in-player episode or video changes on Netflix, Prime Video, Max, and YouTube.
- Restore the native subtitle layer and menu state when DuetSub is disabled.
- Use the settings page in English, Simplified Chinese, or Traditional Chinese.
- Configure Qwen through Alibaba Cloud Model Studio in China or Singapore, or Doubao through Volcengine Ark, using their Responses APIs.
- Supply your own Qwen Workspace ID; optional Qwen web search remains off by default.
- Read a larger language menu, with additional sizing for Netflix.
- Keep the English line visually primary while retaining a comfortable Traditional Chinese secondary line.

### Validation

- 48 Vitest files / 224 tests passed.
- TypeScript checking passed.
- Standalone Chrome MV3 and Chrome Web Store packages passed release verification.
- The Official Language Pair runtime candidate passed logged-in playback gates on all four supported sites; see `docs/VERIFICATION.md` for exact evidence boundaries.

## 简体中文

DuetSub 0.1.6 在坚持官方字幕优先的同时，让双语观看更加自由。

### 主要更新

- 可从当前节目真实提供的字幕中任选两种经过验证的官方语言。
- 新增独立“语言”选单，可选择上下字幕、交换位置或重新载入官方字幕。
- 改进 Netflix、Prime Video、Max 和 YouTube 上的字幕归属、时间同步、拖动进度与站内换集/换视频处理。
- 关闭 DuetSub 时恢复平台原生字幕层和选单状态。
- 设置界面支持英文、简体中文和繁体中文。
- 通过 Responses API 接入阿里云百炼千问（中国区/新加坡区）与火山方舟豆包。
- 千问 Workspace ID 由用户自行填写，可选联网搜索默认关闭。
- 放大播放器语言选单，并针对 Netflix 进一步增大尺寸。
- 保持英文主字幕的视觉优先级，同时让繁体中文副字幕舒适易读。

### 验证

- 48 个 Vitest 文件、224 项测试全部通过。
- TypeScript 检查通过。
- Chrome MV3 独立发布包和 Chrome 应用商店发布包均通过发布验证。
- 官方语言自由配对的运行时版本候选已在四个支持站点完成登录播放验证；准确的证据边界见 `docs/VERIFICATION.md`。
