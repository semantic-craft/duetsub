# DuetSub v0.1.5

This patch fixes a Prime Video timeline race that could make bilingual subtitles appear about six seconds before dialogue.

## Highlights

- Tracks audio and video timestamp offsets separately for each Prime Video `MediaSource`.
- Uses only the active `#dv-web-player` source when selecting the subtitle timeline offset, so a preview stream can no longer overwrite the main player clock.
- Waits through Prime Video's observed zero-to-offset initialization transition instead of accepting an early zero.
- Adds regression coverage for both delayed `+6s` initialization and a later preview stream reporting `0s`.

## Validation

- Full Vitest behavior suite and TypeScript checking.
- Reproducible Chrome MV3 release and Chrome Web Store archive verification.
- Logged-in Prime Video comparison of matching native and DuetSub cue boundaries after reloading the exact extension build.
