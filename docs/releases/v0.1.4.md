# DuetSub v0.1.4

This release improves subtitle reliability on Prime Video and Netflix and refreshes the Chrome Web Store package.

## Highlights

- Captures Prime Video fragmented subtitle responses, including Akamai payload shapes that the earlier path missed.
- Keeps Prime Video subtitle cues aligned with dialogue across fragmented timelines.
- Keeps Netflix native captions hidden when the player rebuilds or restyles its timed-text DOM, preventing duplicate subtitle layers.
- Scopes Netflix caption observation to the active player and restores discarded native nodes when DuetSub is disabled.
- Refines player controls and packages the least-privilege Chrome Web Store candidate without a committed store identity.

## Validation

- Full Vitest behavior suite and TypeScript checking.
- Reproducible Chrome MV3 release archive verification.
- Separate Chrome Web Store archive verification, including the manifest-key and host-permission boundaries.

## Known boundary

YouTube remains fail-closed when the player does not expose a verifiable timed-text request. DuetSub leaves native subtitles visible instead of guessing a track URL.
