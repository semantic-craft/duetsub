# DuetSub v0.2.0

[English](#english) | [简体中文](#简体中文)

## English

DuetSub 0.2.0 combines the subtitle-aware Qwen translation upgrade with full
Disney+ support for official and machine-translated bilingual subtitles.

### Highlights

- Adds Disney+ to the supported players, using the complete official HLS
  subtitle catalog available to the signed-in viewer.
- Places the DuetSub controls inside the Disney+ player as the leftmost items
  of the right-side control group, immediately before mute.
- Shows only one subtitle renderer at a time: enabling DuetSub hides Disney's
  native captions, while disabling it restores the native layer.
- Uses Disney's whole-program playback clock and a continuous subtitle timeline
  across HLS discontinuities and period-local PTS resets.
- Supports any two verified Disney+ official subtitle tracks, including the
  live-tested Japanese / Traditional Chinese pair.
- Makes the existing explicit **Use AI to retranslate bottom subtitles** action
  available on Disney+, with an MT marker and one-click official restoration.
- Includes the subtitle-aware Qwen prompt upgrade: film/TV scene context,
  complete dialogue semantics, character voice, up to eight adjacent cues,
  deterministic cue ownership, and reasoning disabled.
- Defaults new Qwen configurations to `qwen3.7-plus` without replacing an
  existing saved model choice. AI remains opt-in and official subtitles remain
  the default.

### Validation

- 56 Vitest files / 282 tests passed; one opt-in live suite was skipped.
- TypeScript checking passed.
- Standalone Chrome MV3 and Chrome Web Store packages passed release
  verification as version `0.2.0` with the least-privilege host boundary.
- Logged-in Disney+ playback passed official-pair timing, seeking, native-layer
  restoration, control placement, live MT output, and official restoration.
- No signed subtitle URL, cookie, token, API key, private signing key, or
  proprietary subtitle payload is included in the repository or archives.

## 简体中文

DuetSub 0.2.0 将面向字幕场景的千问翻译提升与完整 Disney+ 适配合并发布，
同时支持官方双语字幕和机器翻译双语字幕。

### 主要更新

- 新增 Disney+ 支持，读取当前登录账号可访问的完整官方 HLS 字幕目录。
- DuetSub 控件嵌入 Disney+ 播放器右侧功能组最左端，位于音量按钮之前。
- 同一时间只保留一套字幕：开启 DuetSub 时隐藏 Disney+ 原生字幕，关闭后恢复。
- 使用 Disney+ 整部节目的播放时钟，并跨 HLS discontinuity 与分段 PTS 重置
  建立连续字幕时间轴。
- 支持任意两条经过验证的 Disney+ 官方字幕轨；实机已验证日语／繁体中文。
- Disney+ 可直接使用现有 **“用 AI 重译下方字幕”**，显示 MT 标记，并可一键
  恢复官方字幕。
- 包含千问字幕提示词提升：理解影视场景、保留完整台词语义与人物语气、结合最多
  8 条相邻 cue、严格保持 cue 归属，并完全关闭推理。
- 新建千问配置默认使用 `qwen3.7-plus`，不会覆盖已有模型选择。AI 仍需用户主动
  触发，默认始终优先官方字幕。

### 验证

- 56 个 Vitest 文件、282 项测试通过；1 个可选真实 API 套件跳过。
- TypeScript 检查通过。
- Chrome MV3 独立发布包和 Chrome 应用商店包均以 `0.2.0` 通过发布检查，
  并保持最小权限边界。
- 登录态 Disney+ 已通过官方双轨时间轴、拖动进度、原生字幕恢复、控件位置、
  真实机器字幕输出和官方字幕恢复验证。
- 仓库与发布包不包含签名字幕 URL、Cookie、Token、API key、私有签名密钥或
  专有字幕载荷。
