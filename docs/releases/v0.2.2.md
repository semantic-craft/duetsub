# DuetSub v0.2.2

[English](#english) | [简体中文](#简体中文) | [繁體中文](#繁體中文)

## English

DuetSub 0.2.2 is a focused playback reliability update for Max and Disney+.

### Highlights

- Loads Max official subtitle metadata on the current single-ID watch URL.
- Replays only same-title playback metadata when Max starts MAIN before
  ISOLATED is ready; VTT responses are never replayed.
- Resolves duplicate Max subtitle adaptations through a causal native-track
  selection probe and fails closed when ownership remains ambiguous.
- Rebinds the controller, overlay, clock, and native-caption state after Max
  in-site navigation or video replacement.
- Keeps Disney+ controls above the player's gesture layer so the validated
  in-player controls remain clickable.

### Validation

- Logged-in Max playback passed direct startup, official English / Traditional
  Chinese rendering, native-caption suppression and restoration, seeking, and
  in-site video replacement.
- The Max picture remained visible across multiple subtitle cues; the earlier
  intermittent black-picture symptom was not reproduced, so its historical
  root cause is not claimed as identified.
- Logged-in Disney+ playback had already passed the control click regression
  on the same source change included in this release.

## 简体中文

DuetSub 0.2.2 是一次聚焦 Max 与 Disney+ 播放可靠性的更新。

### 主要更新

- 在 Max 当前单一内容 ID 播放网址上正确加载官方字幕元数据。
- Max 的 MAIN 早于 ISOLATED 启动时，只重放同一节目的播放元数据；绝不重放
  VTT 响应。
- 通过原生字幕轨选择产生的因果请求确认 Max 重复字幕 adaptation；所有权仍不明确
  时安全停止。
- Max 站内导航或视频元素替换后，重新绑定控制器、字幕层、时钟和原生字幕状态。
- 将 Disney+ 控件保持在播放器手势层之上，使已验收的播放器内控件保持可点击。

### 验证

- Max 登录态播放通过直接启动、官方英文／繁体中文双语显示、原生字幕隐藏与恢复、
  快退快进以及站内视频替换。
- Max 画面跨多个字幕 cue 持续可见；历史间歇性黑屏本轮没有复现，因此不宣称已找到
  旧黑屏根因。
- 同一 Disney+ 源码改动此前已通过登录态控件点击回归验收。

## 繁體中文

DuetSub 0.2.2 是一次聚焦 Max 與 Disney+ 播放可靠性的更新。

### 主要更新

- 在 Max 目前單一內容 ID 播放網址上正確載入官方字幕中繼資料。
- Max 的 MAIN 早於 ISOLATED 啟動時，只重放同一節目的播放中繼資料；絕不重放
  VTT 回應。
- 透過原生字幕軌選擇產生的因果請求確認 Max 重複字幕 adaptation；所有權仍不明確
  時安全停止。
- Max 站內導覽或影片元素替換後，重新綁定控制器、字幕層、時鐘和原生字幕狀態。
- 將 Disney+ 控制項保持在播放器手勢層之上，使已驗收的播放器內控制項保持可點擊。

### 驗證

- Max 登入狀態播放通過直接啟動、官方英文／繁體中文雙語顯示、原生字幕隱藏與恢復、
  快退快進以及站內影片替換。
- Max 畫面跨多個字幕 cue 持續可見；歷史間歇性黑畫面本輪沒有重現，因此不宣稱已找到
  舊黑畫面根因。
- 同一 Disney+ 原始碼變更先前已通過登入狀態控制項點擊回歸驗收。
