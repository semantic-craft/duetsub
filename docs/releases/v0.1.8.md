# DuetSub v0.1.8

[English](#english) | [简体中文](#简体中文)

## English

DuetSub 0.1.8 makes its subtitle-aware AI translation available even when a
title already provides two official subtitle tracks—without changing the
official-first default.

### Highlights

- Replaces the generic **Retranslate** action with
  **Use AI to retranslate bottom subtitles**.
- Uses the current top subtitle track as the source and automatically applies
  the film/TV prompt on Netflix, Prime Video, and Max or the YouTube prompt on
  YouTube.
- Supports English, Simplified Chinese, and Traditional Chinese as explicit
  bottom-subtitle AI targets, following the saved bottom-language preference.
- Defaults new Qwen configurations to `qwen3.7-plus` while preserving existing
  saved model choices.
- Prioritizes complete, natural subtitle translation over character-count or
  reading-speed budgets.
- Reconstructs continuous dialogue across up to eight adjacent cues before
  naturally allocating the complete translation back to the original timeline.
- Keeps Qwen reasoning fully disabled for subtitle translation.
- Skips the translation cache so prompt and model changes can be evaluated
  immediately.
- Keeps the official bottom subtitles visible until the first AI result
  arrives.
- Marks the replacement line as machine-translated and replaces only the
  bottom subtitle timing derived from the top source cues.
- Restores the official subtitle pair with **Reload official subtitles**.
- Keeps official subtitles as the default. Selecting or loading an official
  pair does not contact a translation endpoint; AI retranslation requires an
  explicit user action.

### Validation

- 50 Vitest files / 240 tests passed; one opt-in live API suite was skipped.
- TypeScript checking passed.
- Standalone Chrome MV3 and Chrome Web Store packages passed release
  verification as version `0.1.8`.
- `npm audit --omit=dev` reported zero vulnerabilities.
- A logged-in YouTube run on `iQyg-KypKAA` used the configured
  `qwen3.7-flash` Responses endpoint to generate an MT-marked Simplified
  Chinese bottom cue from the official English top track. Reloading official
  subtitles removed the AI line and restored the available official track.
- The full 45-minute video was not translated to completion, and the other
  supported players were not rerun for this feature; see
  `docs/VERIFICATION.md` for the exact evidence boundary.

## 简体中文

DuetSub 0.1.8 在保持官方字幕优先这一默认规则的同时，让已有官方双轨的节目
也能主动使用真正面向字幕场景的 AI 翻译。

### 主要更新

- 将含义宽泛的 **“重新翻译”** 改为
  **“用 AI 重译下方字幕”**。
- 以上方当前字幕为原文；Netflix、Prime Video、Max 自动使用影视剧提示词，
  YouTube 自动使用 YouTube 提示词。
- AI 下方字幕支持英文、简体中文和繁体中文，并沿用已保存的下方语言偏好。
- 新建千问配置默认使用 `qwen3.7-plus`，不会覆盖已经保存的模型选择。
- 翻译质量、语义完整和自然对白优先，不再向模型发送字数或阅读速度预算。
- 先用最多 8 条相邻 cue 还原连续台词，再把完整译文自然分配回原时间轴。
- 千问字幕翻译完全关闭推理。
- 强制跳过翻译缓存，方便立即检验提示词和模型调整。
- 第一批 AI 结果返回前继续保留官方下方字幕。
- 只替换由上方源 cue 时间轴生成的下方字幕，并显示机器翻译标记。
- 点击 **“重新加载官方字幕”** 即可恢复官方语言对。
- 默认仍显示官方字幕。选择或载入官方语言对不会连接翻译端点，
  只有用户主动操作才会调用 AI 重译。

### 验证

- 50 个 Vitest 文件、240 项测试通过；1 个可选真实 API 测试套件跳过。
- TypeScript 检查通过。
- Chrome MV3 独立发布包和 Chrome 应用商店包均以 `0.1.8` 通过发布验证。
- `npm audit --omit=dev` 未发现漏洞。
- 登录态 YouTube 视频 `iQyg-KypKAA` 已使用已配置的
  `qwen3.7-flash` Responses 端点，以上方官方英文字幕生成带 MT 标记的
  简体中文下方字幕；重新加载官方字幕后，AI 字幕被移除并恢复当前可用的官方轨。
- 未等待整段 45 分钟视频翻译完毕，其他支持的播放器也未针对本功能重新回放；
  准确证据边界见 `docs/VERIFICATION.md`。
