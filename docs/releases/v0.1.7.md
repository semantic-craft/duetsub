# DuetSub v0.1.7

[English](#english) | [简体中文](#简体中文)

## English

DuetSub 0.1.7 expands official-subtitle choice and adds subtitle-aware AI
translation for film, television, and YouTube.

### Highlights

- Choose any two verified official subtitle languages available for the current
  title, place either language on top, swap them, or reload the tracks.
- Keep subtitle ownership, timing, seeking, in-player navigation, and native
  subtitle restoration reliable across Netflix, Prime Video, Max, and YouTube.
- Use the settings and in-player language interface in English, Simplified
  Chinese, or Traditional Chinese.
- Configure Qwen through Alibaba Cloud Model Studio in China or Singapore, or
  Doubao through Volcengine Ark, using OpenAI-compatible Responses APIs.
- Use `qwen3.7-flash` as the first Qwen model candidate. Previously saved model
  choices remain unchanged.
- Translate with separate film/TV and YouTube system prompts that preserve cue
  identity, source timing, dialogue voice, technical details, numbers, units,
  corrections, and operational directions.
- Fit translated text to each cue's duration and reading budget, then apply
  deterministic line breaking without moving text between cues.
- Supply your own Qwen Workspace ID. Optional Qwen web search remains off by
  default.

### Validation

- 49 Vitest files / 233 tests passed; the live API test is opt-in.
- TypeScript checking passed.
- Eight real Qwen Workspace Responses API calls passed across both prompt
  profiles and both translation directions with `qwen3.7-flash`.
- Standalone Chrome MV3 and Chrome Web Store packages passed release
  verification.
- The official-language-pair runtime candidate previously passed logged-in
  playback gates on all four supported sites. Exact `0.1.7` packaged playback
  was not rerun; see `docs/VERIFICATION.md` for the evidence boundary.

## 简体中文

DuetSub 0.1.7 扩展了官方字幕语言选择，并为影视剧和 YouTube
加入真正面向字幕场景的 AI 翻译。

### 主要更新

- 可从当前节目真实提供的字幕中任选两种经过验证的官方语言，自由决定上下顺序、
  一键交换或重新载入字幕轨。
- 改进 Netflix、Prime Video、Max 和 YouTube 上的字幕归属、时间同步、进度拖动、
  站内换集／换视频及平台原生字幕恢复。
- 设置界面和播放器语言界面支持英文、简体中文和繁体中文。
- 通过 OpenAI-compatible Responses API 接入阿里云百炼千问（中国区／新加坡区）
  与火山方舟豆包。
- 千问模型候选默认优先使用 `qwen3.7-flash`，不会覆盖用户已经保存的模型选择。
- 分别使用影视剧与 YouTube 系统提示词，保留 cue 对应关系、源时间轴、人物语气、
  技术细节、数字、单位、纠错和操作方向。
- 根据每条 cue 的显示时长与阅读预算控制译文，再用确定性排版断行，
  不把文字移动到其他 cue。
- 千问 Workspace ID 由用户自行填写，可选联网搜索默认关闭。

### 验证

- 49 个 Vitest 文件、233 项测试通过；真实 API 测试默认不运行。
- TypeScript 检查通过。
- 使用 `qwen3.7-flash` 对两个 prompt profile、两个翻译方向执行 8 次真实
  Workspace Responses API 请求，全部通过。
- Chrome MV3 独立发布包和 Chrome 应用商店发布包均通过发布验证。
- 官方语言自由配对的运行时候选此前已在四个支持站点完成登录播放验证；
  `0.1.7` 最终打包版本未重新执行该真人门槛，准确证据边界见
  `docs/VERIFICATION.md`。
