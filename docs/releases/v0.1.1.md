# DuetSub v0.1.1

First public standalone release of DuetSub.

## Highlights

- Official English + Traditional Chinese subtitle overlays for Prime Video, Netflix, Max, and supported YouTube tracks.
- Player-native DuetSub controls, including corrected Prime, Netflix, and Max anchoring.
- Seek and episode/video replacement lifecycle guards that reject stale cues.
- Current Max `*.prd.media.h264.io` playback manifests, response-time episode ownership, ad-period VTT gaps, and complete-track seek reuse.
- English-primary Max cue alignment that delays slightly early Traditional Chinese cues instead of displaying them before the matching English cue.
- Native subtitle selection and renderer restoration when DuetSub is disabled or acquisition fails.
- Optional DeepSeek, OpenAI-compatible, and loopback translation fallback with per-endpoint permission prompts.
- Stable standalone extension ID and a verified Chrome MV3 release archive.

## Privacy and permissions

Translation endpoints are no longer required install-time hosts. DeepSeek, custom HTTPS, and loopback access are requested only from a user action in the settings page. See `PRIVACY.md` in the repository for details.

## Known boundary

YouTube remains fail-closed when the player does not expose a verifiable timed-text request for the selected title. DuetSub will leave native subtitles visible instead of guessing a track URL.
