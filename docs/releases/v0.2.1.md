# DuetSub v0.2.1

[English](#english) | [简体中文](#简体中文) | [繁體中文](#繁體中文)

## English

DuetSub 0.2.1 is a focused playback reliability update for Prime Video and
the in-player language menu.

### Highlights

- Repairs discovery of Prime Video's current settings and subtitle controls.
- Selects Prime Video official subtitle tracks through the player's own React
  handlers instead of relying on stale menu markup.
- Prevents Prime Video's native captions from overlapping DuetSub. Enabling
  DuetSub leaves one bilingual renderer visible; disabling it restores the
  native caption layer.
- Keeps the DuetSub options menu visible and clickable when a host player
  auto-hides, fades, or clips its native control bar.
- Preserves the official-first model: choose English above and Traditional
  Chinese below after the verified track read reaches 100%.
- Adds public live-playback evidence for the setup flow, Prime Video, Netflix,
  Max, and YouTube.

### Validation

- 56 Vitest files / 284 tests passed; one opt-in live suite was skipped.
- TypeScript checking passed.
- Standalone Chrome MV3 and Chrome Web Store packages passed the release
  verification gates as version `0.2.1`.
- Logged-in Prime Video playback passed official-track reading, the 100%
  chooser state, bilingual rendering, and native-caption overlap regression.
- The final portal-based options menu was also rechecked in logged-in YouTube
  playback.

Disney+ remains supported from the `0.2.0` integration. A fresh Disney+
screenshot was not counted in this run because the current network was
redirected to Disney+'s regional-unavailable page.

## 简体中文

DuetSub 0.2.1 是一次聚焦 Prime Video 与播放器内语言选单可靠性的更新。

### 主要更新

- 修复 Prime Video 当前设置按钮和字幕按钮的识别。
- 通过播放器自身的 React 事件处理器选择 Prime Video 官方字幕轨，不再依赖过期的
  选单结构。
- 防止 Prime Video 原生字幕与 DuetSub 重叠。开启时只保留一套双语渲染，关闭后
  恢复平台原生字幕。
- 宿主播放器自动隐藏、淡出或裁切控制栏时，DuetSub 选项菜单仍保持可见并可点击。
- 继续坚持官方字幕优先：官方轨道读取达到 100% 后，可选择英文在上、繁体中文在下。
- 增加设置流程、Prime Video、Netflix、Max 与 YouTube 的公开真实播放截图。

### 验证

- 56 个 Vitest 文件、284 项测试通过；1 个可选真实 API 套件跳过。
- TypeScript 检查通过。
- Chrome MV3 独立发布包和 Chrome 应用商店包均以 `0.2.1` 通过发布检查。
- Prime Video 登录态播放通过官方轨道读取、100% 可选状态、双语渲染和原生字幕
  重叠回归验证。
- 最终基于 portal 的选项菜单也在 YouTube 登录态播放中重新核对。

Disney+ 支持沿用 `0.2.0` 集成验证。本轮当前网络被重定向到 Disney+ 地区不可用
页面，因此没有把新的 Disney+ 截图计为通过。

## 繁體中文

DuetSub 0.2.1 是一次聚焦 Prime Video 與播放器內語言選單可靠性的更新。

### 主要更新

- 修復 Prime Video 目前設定按鈕和字幕按鈕的識別。
- 透過播放器本身的 React 事件處理器選擇 Prime Video 官方字幕軌，不再依賴過期的
  選單結構。
- 防止 Prime Video 原生字幕與 DuetSub 重疊。開啟時只保留一套雙語渲染，關閉後
  恢復平台原生字幕。
- 宿主播放器自動隱藏、淡出或裁切控制列時，DuetSub 選項選單仍保持可見並可點擊。
- 繼續堅持官方字幕優先：官方軌道讀取達到 100% 後，可選擇英文在上、繁體中文在下。
- 增加設定流程、Prime Video、Netflix、Max 與 YouTube 的公開真實播放截圖。

### 驗證

- 56 個 Vitest 檔案、284 項測試通過；1 個可選真實 API 套件跳過。
- TypeScript 檢查通過。
- Chrome MV3 獨立發佈包和 Chrome 線上應用程式商店包均以 `0.2.1` 通過發佈檢查。
- Prime Video 登入狀態播放通過官方軌道讀取、100% 可選狀態、雙語渲染和原生字幕
  重疊回歸驗證。
- 最終基於 portal 的選項選單也在 YouTube 登入狀態播放中重新核對。

Disney+ 支援沿用 `0.2.0` 整合驗證。本輪目前網路被重新導向至 Disney+ 地區不可用
頁面，因此沒有把新的 Disney+ 截圖計為通過。
